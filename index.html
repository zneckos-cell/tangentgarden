Privacy & trust

Privacy and Keyboard Input

Tangentgarden uses keyboard input because typing is a core gameplay mechanic.

🛡️

Our commitment to you

  • Only reads keyboard input while the game window is focused.
  • Does not monitor what you type in other applications.
  • Does not capture passwords.
  • Does not function as a keylogger.
  • Does not collect sensitive personal information through keyboard input.
