# Input source snapshot — 2026-11-01

The four `.cs.txt` files are complete, unmodified copies of the corresponding
files in `tangentgarden/`. Plain-text extensions make them readable on static
hosting. `Website/index.html` displays three consecutive excerpts with source
line numbers; only indentation and HTML escaping are changed for display.

When input code changes, refresh these copies and the excerpts together, update
the visible snapshot date, and verify both against the current source. These
files show the ordinary input path, not the whole game or a reproducible build.
They do not establish that a distributed executable matches this snapshot.

The ordinary Windows path polls key states across applications. Pausing and app
exclusions suppress gameplay registration, not polling. Samples are transient;
daily and lifetime per-key totals are saved locally. Account authentication,
statistics uploads and the local typing trial have separate code paths.
